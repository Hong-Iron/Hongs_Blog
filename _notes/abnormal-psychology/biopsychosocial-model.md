<div class="callout-title callout-title--default" markdown="span">요약</div>

마음의 병을 몸(생물), 마음(심리), 환경(사회) 세 겹의 원인이 겹친 결과로 보고, 겹마다 맞는 치료를 짝짓는 지도다. 한 입장만 고집하면 놓치는 원인을 빠짐없이 챙기게 해 준다는 점이 강점이다. 대신 "모든 것이 관련 있다"로 끝나기 쉬워서, 한 사람에게 어느 원인이 가장 중요한지는 따로 판단해야 한다.

</div>


## 예시로 보기

대학 졸업 뒤 1년째 취업하지 못한 채 우울해진 Q를 세 겹으로 본다[^s1].

| 겹 | Q에게서 찾은 원인 | 짝이 되는 개입 |
|---|---|---|
| 생물 | 우울증 가족력, 불규칙한 수면 | 약물치료 |
| 심리 | "취업 못 한 나는 실패자"라는 신념, 사람을 피하는 행동 | 인지치료, 행동치료 |
| 사회 | 부모와의 갈등, 청년 실업 | 가족치료, 사회 정책 |

어느 한 겹만 고치면 나머지가 다시 우울을 끌어당긴다. 약으로 기분이 조금 나아져도 부모와의 갈등이 계속되면 다시 가라앉는다. 그래서 세 겹을 함께 본다.

## 정의

슬라이드는 생물학적(Biological), 심리적(Psychological), 사회적(Social) 요인을 겹친 세 원으로 그린다. 원이 겹친다는 것은 요인들이 서로 영향을 주고받는다는 뜻이다[^1]. 요인마다 원인과 치료를 짝지으면 다음과 같다[^2].

| 요인 | 세부 요인 | 원인의 예 | 치료 |
|---|---|---|---|
| 생물학적 | 유전적 요인 | 유전자 이상 | 유전자 치료 |
| | 신경해부학적 요인 | 뇌의 구조적 이상과 결함 | 뇌절제술 |
| | 신경생리학적 요인 | 신경전달물질 이상 | 약물치료 |
| 심리적 | 정서동기적 요인 | 정서를 체험하고 표현하는 방식 | 정신역동치료 |
| | 인지적 요인 | 역기능적 신념, 부정적 사고 | 인지치료 |
| | 행동적 요인 | 부적응적 행동양식, 대인기술 부족 | 행동치료 |
| 사회적 | 개인적 환경요인 | 결혼상태, 가족구조, 직업 | 가족치료 |
| | 사회문화적 요인 | 성차별, 사회적 낙인 | 사회교육, 사회정책 |
| | 사회경제적 요인 | 가난과 빈곤, 경제 양극화 | 사회복지, 경제발전 |

심리적 요인의 세 칸은 앞의 이론적 입장과 하나씩 맞물린다. 정서동기적 요인은 [정신분석적 입장](/Hongs_Blog/studies/abnormal-psychology/psychoanalytic-perspective/), 인지적 요인은 [인지적 입장](/Hongs_Blog/studies/abnormal-psychology/cognitive-perspective/), 행동적 요인은 [행동주의적 입장](/Hongs_Blog/studies/abnormal-psychology/behavioral-perspective/)이다. 생물학적 요인은 [생물의학적 입장](/Hongs_Blog/studies/abnormal-psychology/biomedical-perspective/)이다. 이 모델은 네 입장을 버리지 않고 한 표 안에 자리를 준다[^s2].

## 연결

- 헷갈리는 짝: [취약성-스트레스 모델](/Hongs_Blog/studies/abnormal-psychology/vulnerability-stress-model/). 둘 다 통합적 입장이다. 취약성-스트레스 모델은 "타고난 약점과 스트레스가 만날 때 발병한다"는 시간의 흐름을, 생물심리사회적 모델은 "원인이 어느 수준에 있고 어떤 치료가 맞나"라는 수준의 지도를 준다.
- 이후 모든 장애의 원인과 치료는 이 표의 칸에 나눠 담긴다.

## 확인 문제

<details markdown="1"><summary markdown="span"><b>C1</b> 생물심리사회적 모델의 세 요인을 쓰고, 요인마다 세부 요인 하나와 짝이 되는 치료를 쓰라.</summary>


**답:** 생물학적: 신경생리학적 요인(신경전달물질 이상) → 약물치료. 심리적: 인지적 요인(역기능적 신념) → 인지치료. 사회적: 개인적 환경요인(가족구조) → 가족치료. 다른 세부 요인과 치료의 짝도 표에 맞으면 정답이다.

</details>

<details markdown="1"><summary markdown="span"><b>C2</b> 다음 개입은 생물심리사회적 모델의 어느 요인·세부 요인에 해당하는가? (a) 사회기술 훈련 (b) 정신장애 낙인을 줄이는 공익 광고 (c) 꿈 분석 (d) 기초생활수급 지원</summary>


**답:** (a) 심리적·행동적 요인(대인기술 부족) → 행동치료. (b) 사회적·사회문화적 요인(사회적 낙인) → 사회교육. (c) 심리적·정서동기적 요인 → 정신역동치료. (d) 사회적·사회경제적 요인(빈곤) → 사회복지.

</details>

<details markdown="1"><summary markdown="span"><b>C3</b> 취약성-스트레스 모델과 생물심리사회적 모델은 모두 통합적 입장이다. 두 모델이 답하는 질문은 어떻게 다른가?</summary>


**답:** 취약성-스트레스 모델은 "왜 하필 이 사람이, 하필 이때 발병했나?"에 답한다. 미리 있던 취약성과 뒤에 온 스트레스의 만남으로 설명한다. 생물심리사회적 모델은 "원인이 어떤 수준에 있고 무엇으로 치료하나?"에 답한다. 원인을 생물·심리·사회 수준으로 나누고 수준별 치료를 짝짓는다.<br>
**흔한 오답:** "취약성은 생물, 스트레스는 사회"로 둘을 같은 것으로 보는 경우. 취약성에는 인지도식과 대처방식 같은 심리적 요인도 들어 있다.

</details>

[^2]: 4-1학기/이상 심리학/1.수업자료/01.이상심리학.pdf, p.57
