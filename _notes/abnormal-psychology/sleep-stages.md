<div class="callout-title callout-title--default" markdown="span">요약</div>

잠은 스위치를 끄듯 한 번에 꺼지는 상태가 아니라, 얕은 잠에서 깊은 잠으로 내려갔다가 꿈꾸는 잠으로 올라오는 한 바퀴를 밤새 여러 번 도는 과정이다. 깊은 잠은 몸을 회복시키고, 꿈꾸는 REM 수면은 뇌를 정리한다. 그래서 오래 자는 것보다 이 바퀴를 고르게 여러 번 도는 것이 숙면이다. 어느 단계에서 문제가 생기느냐에 따라 수면장애의 모습이 달라진다.

</div>


## 예시로 보기

밤 11시에 잠든 사람의 여덟 시간을 따라가 본다[^1].

| 시간 | 단계 | 일어나는 일 |
|---|---|---|
| 11:00 | 깨어 있음 → N1 | 잠이 들 듯 말 듯한 얕은 잠. 몸이 움찔하기도 한다 |
| 11:10 | N2 | 얕은 잠. 뇌파에 수면방추와 K복합이 나타난다 |
| 11:40 | N3 | 깊은 잠(서파 수면). 깨우기 가장 어렵다 |
| 12:30 | REM | 눈이 빠르게 움직이고 생생한 꿈을 꾼다 |
| 1:00~7:00 | 같은 순서를 반복 | 밤 전반부에는 N3가 길고, 후반부로 갈수록 REM이 길어진다 |

이 시간표는 p.49 그림의 흐름을 따라 만든 예다. 한 바퀴는 대략 90분이고, 하룻밤에 4~5번 돈다[^s1].

## 정의

### 수면 단계[^1][^2]

| 단계 | 뇌파 | 특징 |
|---|---|---|
| 깨어 있음 | 베타파(13~40Hz)와 알파파(8~12Hz) | |
| N1(1단계) | 4~16Hz의 파와 알파파 | 잠드는 과정의 얕은 잠 |
| N2(2단계) | 수면방추(13~15Hz)와 K복합 | 전체 수면에서 가장 큰 비중 |
| N3(3·4단계) | 느리고 큰 델타파(1~4Hz) | 깊은 잠. 몸의 회복 |
| REM 수면 | 깨어 있을 때와 비슷한 빠른 파 | 빠른 안구 운동, 생생한 꿈. 뇌의 정리 |

p.49의 그림은 깊은 잠을 3단계와 4단계로 나누는 옛 분류(Hartmann)이고, p.50의 그림은 둘을 N3로 합친 현재 분류다. 미국수면의학회가 2007년에 3·4단계를 N3로 합쳤다[^s2].

REM 수면 동안에는 뇌는 활발하지만 몸의 근육은 거의 완전히 풀려 있다. 그래서 꿈속에서 달려도 몸은 움직이지 않는다[^s3]. 이 근육 이완이 깨지거나 엉뚱한 때 나타나면 REM 수면 행동장애, 탈력발작, 가위눌림이 생긴다.

### 수면의 중요성[^3]

- 신체적·정신적 피로 회복
- 면역 기능 강화
- 성장 호르몬 분비와 세포 재생
- 기억력 강화와 학습 능력 향상
- 감정 조절과 스트레스 해소

### 나이별 적정 수면 시간[^4]

| 나이 | 시간 |
|---|---|
| 신생아(0~3개월) | 14~17 |
| 영아(4~11개월) | 12~15 |
| 유아(1~2세) | 11~14 |
| 미취학 아동(3~5세) | 10~13 |
| 학령기 아동(6~13세) | 9~11 |
| 청소년(14~17세) | 8~10 |
| 성인(18~64세) | 7~9 |
| 노인(65세 이상) | 7~8 |

### 숙면[^5]

단순히 오래 자는 것이 숙면이 아니다. 수면 주기를 여러 번 고르게 반복해 깊은 잠(N3)에서 몸을 회복하고, REM 수면에서 뇌를 정리하고 꿈을 꾸는 과정을 충분히 거친 상태가 숙면이다. 수면 단계가 깨지면 피로, 주의력·기억력 저하, 면역력과 대사 기능 저하가 생긴다.

### 수면다원검사(polysomnography)[^6]

수면장애를 진단하는 객관적 표준 검사다. 환자가 하룻밤 검사실에서 자는 동안 뇌파, 안구 운동, 호흡, 심전도, 산소포화도, 근육 움직임을 측정하고 비디오로 녹화한다. 수면의 질, 수면 단계, 호흡 상태, 수면 중 움직임을 알 수 있다.

## 확인 문제

<details markdown="1"><summary markdown="span"><b>C1</b> 수면 단계 넷(N1, N2, N3, REM)의 특징을 하나씩 쓰고, 숙면이 무엇인지 한 문장으로 쓰라.</summary>


**답:** N1: 잠드는 과정의 얕은 잠. N2: 수면방추와 K복합이 나타나는 얕은 잠. N3: 느린 델타파의 깊은 잠, 몸의 회복. REM: 빠른 안구 운동과 생생한 꿈, 근육 이완, 뇌의 정리. 숙면은 오래 자는 것이 아니라 수면 주기를 여러 번 고르게 돌아 N3와 REM을 충분히 거친 상태다.

</details>

<details markdown="1"><summary markdown="span"><b>C2</b> 깊은 잠(N3)은 밤 전반부에, REM 수면은 밤 후반부에 많다. 이 분포를 알면 어떤 이상 행동이 밤의 어느 때 일어날지 예측할 수 있는 이유를 쓰라.</summary>


**답:** 각 이상 행동은 특정 수면 단계에서 생기기 때문이다. 깊은 잠에서 반쯤 깨는 수면보행증과 야경증(NREM 각성장애)은 N3가 많은 밤 전반부에, 꿈을 몸으로 옮기는 REM 수면 행동장애와 악몽은 REM이 긴 밤 후반부에 주로 나타난다.

</details>
