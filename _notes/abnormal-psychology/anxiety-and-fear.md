<div class="callout-title callout-title--default" markdown="span">요약</div>

공포는 눈앞의 뚜렷한 위험에 대한 반응이고, 불안은 무엇인지 분명하지 않은 위험에 대한 반응이다. 둘 다 위험에 대비하게 해 주는 정상적인 경보 장치다. 경보가 실제 위험이 없는데 울리거나, 위험에 비해 지나치게 크거나, 위험이 사라진 뒤에도 꺼지지 않으면 병적이다. 병적인 불안과 공포가 주된 증상인 장애들을 불안장애라 부르고, 무엇을 두려워하느냐로 나눈다.

</div>


## 예시로 보기

한밤중 산길에서 두 사람이 서로 다른 것을 느낀다[^s1].

- 눈앞에 멧돼지가 나타나자 BO의 심장이 뛰고 몸이 굳는다. 대상이 구체적이고 위험이 임박했다. **공포**다.
- 아무것도 보이지 않는데 BP는 "뭔가 나올 것 같다"며 계속 두리번거린다. 대상이 막연하고 위험이 모호하다. **불안**이다.

둘 다 정상이다. 그런데 BP가 집 안에 있을 때도, 몇 달째, 이유도 모른 채 "뭔가 잘못될 것 같다"는 느낌에 시달린다면 병적 불안이다.

## 정의

### 공포와 불안[^1]

| | 공포 (fear) | 불안 (anxiety) |
|---|---|---|
| 위험의 모습 | 구체적이고 임박한 강력한 위험 | 막연하고 모호한 위험 |
| 예 | 달려드는 개 | "무슨 일이 생길 것 같다" |

### 정상적 불안과 병적 불안[^2]

불안 자체는 위험에 대비하게 하는 정상적 반응이다. 다음 세 경우에 병적 불안이 된다.

- **비현실적 불안:** 실제 위험이 없는데 느낀다.
- **과도한 불안:** 위험의 크기에 비해 지나치게 크다.
- **지속적 불안:** 위험이 사라진 뒤에도 오래 이어진다.

### 불안장애의 종류

불안장애는 불안과 공포를 주된 증상으로 하는 장애들이다. 병적 불안이 나타나는 양상과, 불안을 느끼는 대상·상황에 따라 나눈다[^2].

| 장애 | 무엇을 두려워하나[^3] |
|---|---|
| [분리불안장애](/Hongs_Blog/studies/abnormal-psychology/separation-anxiety-disorder/) | 집이나 애착 대상과 떨어지는 것 |
| [선택적 함구증](/Hongs_Blog/studies/abnormal-psychology/selective-mutism/) | 말하는 것이 기대되는 사회적 상황. 정상적인 언어 능력이 있어도 말하지 않는다 |
| [특정공포증](/Hongs_Blog/studies/abnormal-psychology/specific-phobia/) | 특정한 대상이나 상황 하나 |
| [사회불안장애](/Hongs_Blog/studies/abnormal-psychology/social-anxiety-disorder/) | 사회적 상황, 남의 평가 |
| [공황장애](/Hongs_Blog/studies/abnormal-psychology/panic-disorder/) | 예기치 못한 공황발작과 그 재발 |
| [광장공포증](/Hongs_Blog/studies/abnormal-psychology/agoraphobia/) | 빠져나오거나 도움받기 어려운 여러 장소 |
| [범불안장애](/Hongs_Blog/studies/abnormal-psychology/generalized-anxiety-disorder/) | 많은 사건과 활동 전반. 과도한 걱정 |

위로 갈수록 두려움의 대상이 구체적이고, 아래로 갈수록 막연하다. 특정공포증은 공포 쪽에, 범불안장애는 불안 쪽에 가깝다.

## 확인 문제

<details markdown="1"><summary markdown="span"><b>C1</b> 다음은 공포인가, 불안인가? (a) 발표 차례가 3주 뒤인데 "뭔가 잘못될 것 같다"는 느낌이 계속 든다 (b) 엘리베이터 문이 닫히는 순간 숨이 턱 막힌다</summary>


**답:** (a) 불안: 위험이 막연하고 아직 오지 않았다. (b) 공포: 구체적인 대상(닫히는 엘리베이터)이 눈앞에 있고 반응이 즉각적이다.<br>
**가르는 질문:** 위험이 구체적이고 임박했는가, 막연하고 모호한가.

</details>

<details markdown="1"><summary markdown="span"><b>C2</b> 병적 불안의 세 기준(비현실적, 과도한, 지속적)에 각각 해당하는 사례를 하나씩 만들라.</summary>


**답:** 비현실적: 안전한 집 안에서 "곧 무너질 것 같다"며 불안해한다. 과도한: 쪽지 시험 하나에 며칠 밤을 새우고 구토할 만큼 불안해한다. 지속적: 교통사고가 난 지 1년이 지났는데도 매일 차를 타기 전 불안이 줄지 않는다.

</details>
